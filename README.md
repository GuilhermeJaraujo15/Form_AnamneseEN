This form was actually a hands-on group project for my Systems Development course at SENAI, where we wrote every structural part of the code by hand...

The goal of this project is to develop the logic for a nutritional screening system. Unlike simple scripts, we were asked to build an application capable of modeling a real patient using objects and processing that data to generate automatic diagnoses and simulations of health goals.
